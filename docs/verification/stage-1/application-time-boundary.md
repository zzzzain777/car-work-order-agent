# 试驾申请时间边界回归

## 发现与处理

模拟政策 `STORE-A-MX-7-test-drive-v1.md#rule-1` 规定：按上海时区，每日 10:00（含）至 17:00（不含）可提交试驾申请。此前只要首位检索片段含时间范围，17:00 也可能进入模型并生成候选建议。固定反例在修复前得到 `CANDIDATE`。

现在建议流程在模型调用前核对首位政策原文和任务中的试驾时间。10:00、16:59:59 可继续；09:59:59、17:00 转人工核对，模型调用为零。对不能明确识别为“每日起点含、终点不含、上海时区”的政策片段，也转人工核对。检索阶段仍可召回范围外的政策，供后续说明原因。

这属于确定性业务规则，由 Java 校验；不能把这个改进算作大模型理解政策的效果。政策和车源均为模拟数据，候选建议也不代表预约或真实分配。
