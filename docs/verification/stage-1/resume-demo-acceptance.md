## 面试前怎么复现

1. 在项目根目录执行 `bash probes/stage-1/java-pgvector-smoke.sh`。检查 C02 测试通过，并对照上面的逐步结果；这一步不需要模型 API。
2. 启动 `carSystem:8080`、Agent 数据库及 Agent 的 `policy-rag,deepseek,bailian-embedding` 三组配置。全程在**同一个浏览器**使用 `localhost`。
3. 用本地测试客户在 `http://localhost:8080/api/index.html` 新建一条明确标为模拟的待分配试驾工单，记下工单号；切换管理员，在 `http://localhost:8091/agent-demo.html` 创建 Agent 任务，**保留该标签页**。
4. 切回该工单客户，打开任务给出的 `customer-store.html` 链接，输入模拟位置 `31.2304, 121.4737`、车型 `MX-7`、`2026-11-07 14:00`，选择 `STORE-C`。再切回管理员，点击“重新检查”和“刷新任务，查看客户选择”，然后生成建议。

第 4 步的固定模拟时段只在 **2026-11-07 之前**适合现场重跑；之后须更新模拟门店时段与对应政策，不得把过期数据当实时车源。页面刷新会丢失当前任务编号，因此演示时保留管理员标签页。
