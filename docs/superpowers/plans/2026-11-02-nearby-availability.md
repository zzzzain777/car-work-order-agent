# 模拟附近门店可用性接线计划

**目标：** 用可运行的 Java 代码给出距离最近五家模拟门店的试驾车和时段状态，不执行客户选店或真实预约。

**依据：** [附近门店与客户选店设计](../specs/2026-10-28-nearby-store-selection-design.md)及 [C02 固定输入](../../../data/eval/store-selection/c02-v1.json)。

**分工：** 复用已有 `NearbyStoreSelector`；新增独立的模拟结构化门店数据与只读可用性查询。客户身份、选店任务写入及状态图留在下一项，不把管理员补充信息接口冒充客户选择。

## 实施与验收

1. 先写失败测试：六家输入只能展示最近五家；B 无车、D 满额仍展示但不可选；F 虽有车也不能顶替；数据查询失败只把该店标为未知；过去时间和非法坐标被拒绝。
2. 新增模拟门店数据文件及读取器；按精确车型编号、指定时段查询模拟状态，所有结果带“模拟”和查询时间，不读真实车源。
3. 接入纯 Java 最近五家查询服务，并在已有管理员演示页提供受会话与 CSRF 保护的只读模拟查询。运行新增测试与默认完整 Maven 测试，记录本阶段只覆盖“展示”，不把它计作客户选店完成。
