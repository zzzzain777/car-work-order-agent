# 任务与只读预览接通计划

**目标：** 用已验证的管理员 Session 在 Agent 内部创建、更新和读取任务；预览结果按版本保存。

**现状：** `ReadOnlyAdviceFlow` 可做一次性预览，`JdbcAgentTaskStore` 可持久化任务，但两者尚未连接。

**设计：** 新建 `AgentTaskWorkflow`，每次操作先经 `carSystem` 的 `/api/user/current` 取得管理员 ID。创建时读取待分配试驾工单；补充信息和读取任务均只使用这个管理员 ID。刷新预览时先比较工单最小快照，再调用只读流程，最后用数据库版本条件更新保存精简预览。登录失效不保存预览，工单变化记为过期。此阶段只提供 Java 内部服务，不开放浏览器写接口或真实分配。

**取舍：** 任务刷新会为快照比较额外读取一次工单。这样可在政策检索前发现已知变化；确认前仍必须重新读取工单，此处不宣称消除跨系统竞争条件。

## 实施与验收

1. 在隔离 PostgreSQL 探针中先写测试：正常管理员创建→补充→刷新；普通用户与撤销会话被拒；工单更新时间变化后过期；预览计算中发生补充更新时旧预览不能覆盖新任务。
2. 实现 `AgentTaskWorkflow` 和 Spring 配置接线；运行探针与默认完整测试。
3. 更新验证记录；提交推送。测试用身份和政策均为模拟数据，不把结果写成真实管理员联调。
