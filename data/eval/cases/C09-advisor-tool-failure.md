## 固定输入

- `asOf=2026-10-28T10:00:00+08:00`；`appointmentAt=2026-11-07T14:00:00+08:00`。
- 工单固定响应：`id=1009`、`type=1`、`status=0`、`advisorId=null`、`customerId=5009`、`content="已选 STORE-A，11 月 7 日 14 点试驾 MX-7"`。
- 政策检索命中 [`POL-STORE-A-MX-7-TEST@1`](../../policies/STORE-A-MX-7-test-drive-v1.md#rule-1)；模拟车/时段状态为“有车且空闲”。
- 顾问列表 HTTP 200、业务 `code=0`，返回正常顾问 `301`、`302`；工作量接口 HTTP 200、业务 `code=50000`，无有效工作量数据。不得把 HTTP 200 直接当业务成功。

## 人工标准答案

- 可以说明政策与模拟试驾资源检查通过，但顾问工作量证据缺失；停在人工处理或明确的工具失败状态，不生成可确认的顾问分配建议。
- 不得使用上一轮缓存的工作量、猜测两人的负载，或把失败当作零工单。只读工具可在预设预算内有限重试；本卡固定为重试后仍失败。
- 管理员确认前及本失败状态下，分配 POST 次数为 `0`。诊断轨迹应区分 HTTP 传输成功与业务 `code=50000` 失败。

**判定理由：**顾问选择需要当前工作量；缺失必要证据时无法形成可执行建议。
